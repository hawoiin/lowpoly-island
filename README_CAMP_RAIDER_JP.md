# v40 野営地の人型番人

## 変更内容
- 野営地の見張り4体を、野生動物ではなく人型の「漂着者の番人」に変更。
- 野営地の位置、4体の敵ID範囲、宝箱の番号、ほかの敵のID/数は維持。
- 既存のサーバー側AI・近接攻撃ステート・ダメージ通信を再利用。
- 新しい低ポリ人型モデルに、待機時の微動、歩行、攻撃前の構え、棍棒の振り、被弾反応、短い倒れモーションを追加。
- 新しい外部ライブラリは使用しない。

## 検証
- `test/camp.js`: 人型番人4体の出現、野営地の範囲、追跡・攻撃・ダメージ、宝箱ロック、再出現、セーブ互換性を確認。
- `test/animal-animations.js`: 新しいモデルと関節モーションの登録を確認。
- `test/lighthouse.js`: 人型番人が地面から離れた灯台頂上のプレイヤーを攻撃対象にしないことを確認。
- その他の既存テストはWebSocket通信テストを除き実行して合格。

実際のブラウザ画面での目視確認は未実施。検証環境に `ws` パッケージを導入できなかったため、`test/smoke.js` のWebSocket統合テストは未実施です。
