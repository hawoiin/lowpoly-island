# v52 — 野営地番人の攻撃モーション再調整

## 変更点
- 番人の棍棒攻撃を、肩の前後回転を主軸にした動きへ変更。
- 構えでは棍棒を頭上かつ少し前へ持ち上げ、腕が体の横へ大きく逃げないようにした。
- 振り下ろしでは胴体の前傾、肩・肘・手首の回転を連動させ、前方(+Z)へ下がる軌道に変更。
- 回復時は攻撃終端と同じ姿勢から通常姿勢へ戻る。
- サーバー側の敵AI、攻撃開始条件、予備動作時間、ダメージ、攻撃判定、攻撃間隔は変更していない。
- 敵モデル、野営地の数・配置、敵ID、既存のゲーム機能は変更していない。
- タイトル画面のバージョン表示と `shared.js` のキャッシュキーを v52 に更新。

## テスト
`node test/camp-guard-attack-animation.js` で次を確認する。
- 頭上へ構える姿勢と、前下方へ振り切る姿勢が有限値である。
- 棍棒の先端が構えより下へ移動し、振り下ろし中盤に前方へ進む。
- 棍棒が攻撃中に真横へ大きく振り出されない。
- 構え→攻撃→回復の姿勢が連続している。
- サーバーの攻撃設定が変更されていない。

## 確認範囲について
この更新では、攻撃ポーズ関数とモデルの関節階層を使った回帰テストを実行した。実際のブラウザ画面・Render上での見た目は、この環境では直接確認していないため、公開後に野営地の番人と戦って最終確認する必要がある。
