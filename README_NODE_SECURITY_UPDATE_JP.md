# Node.js セキュリティ更新（2026-10-21）

この更新は、ゲームコードや通信仕様を変えず、Render 上の Node.js 実行バージョンを固定するものです。

- 2026年10月21日公開の Node.js 24.22.1（LTS）を指定しています。
- `.node-version` をリポジトリのルートと、ゲーム本体 `lowpoly-island-v28-render-deploy/` の両方に置いています。Render の Root Directory がどちらを指していても、バージョン指定を見つけやすくするためです。
- `package.json`、`package-lock.json`、ゲームのソースコード、ワールド保存形式は変更していません。

## Render に反映する前の注意

1. 現在のワールドを管理画面からエクスポートするなどして、必ず別の場所へバックアップしてください。Render の永続ディスクを構成していない場合、再デプロイで `world.json` が残る保証はありません。
2. Render のサービス設定 → Environment に `NODE_VERSION` が既にある場合は、`.node-version` よりそちらが優先されます。その値を `24.22.1` に変更するか、環境変数を削除して `.node-version` を使ってください。
3. デプロイ完了後、Deploy Logs に表示される Node.js のバージョンを確認してください。ファイルを追加しただけでは、現在稼働中の Render サービスは更新されません。

## PHP の脆弱性について

このプロジェクトのサーバーは Node.js で動作しており、確認したプロジェクトには PHP の実行コードはありません。そのため、PHP 固有の脆弱性は直接の対象ではありません。ただし、それだけでサーバー全体の安全性が保証されるわけではありません。
