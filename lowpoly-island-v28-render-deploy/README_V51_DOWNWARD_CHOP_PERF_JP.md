# v51 — 番人の振り下ろし攻撃と性能計測

## 攻撃モーション
- 野営地番人の右腕と棍棒を、頭上に構えてから前下方へ振り下ろす軌道に変更。
- 構えでは棍棒の頭が頭部より高い位置に来ること、攻撃時は先端が下へ・前方へ動くことを、モデルの階層座標を使う回帰テストで確認。
- サーバー側の攻撃力、当たり判定、攻撃タイミング、敵AIは変更していない。

## 性能計測
- F8キーで画面右下にパフォーマンス表示をON/OFF（標準はOFF）。
- FPS、最大フレーム間隔、JS更新+描画呼び出し時間、描画コール、三角形数、Geometry/Texture数、敵/採集物/建築数、DPRを表示。
- これは性能計測だけで、追加の負荷最適化は行っていない。実測値を見てから次の最適化対象を決める。
