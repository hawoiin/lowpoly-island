# v60.4 ダンジョン起動エラー修正

## 修正内容
- `rockRim()` で広間の半径引数 `rx` / `rz` を、同名の `const` で関数内再宣言していたため、座標計算時に初期化前参照（TDZ）となり、ダンジョン生成時に起動が停止していました。
- 個々の岩サイズを `rockRx` / `rockRy` / `rockRz` に改名し、配置計算では広間の半径引数を保持します。
- 回帰テスト `test/rogue-dungeon-boot-init.js` を追加し、ダンジョン生成の岩配置関数を実行して初期化エラー・不正座標・不正スケールがないことを検査します。
- `favicon.ico` の404表示も避けるため、小さなSVGファビコンをHTMLに埋め込みました。
- バージョン表示と `shared.js` キャッシュキーを v60.4 に更新しました。

## 確認
起動用の `rockRim()` 回帰テスト、ダンジョン地形テスト、および既存の依存不要テストを実行します。Render上でのブラウザ起動確認は、再デプロイ後に必要です。
