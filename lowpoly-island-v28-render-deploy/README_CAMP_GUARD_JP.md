# v43 — プレイヤー比率に合わせた野営地番人

## デザイン方針
- プレイヤーと同じ箱型ローポリのルールを使い、大きめの頭、幅広い胴体、短く太い四肢にする。
- 目・鼻・口、髪/頭布、ベルト、簡単な胸当て、棍棒だけにパーツを限定し、以前の細身モデルより装備の細部を減らす。
- 足の接地面はモデル原点 y=0 に収まり、モデルの高さは髪を含め約1.53m。

## 安全性
- 旧モデル `raider` / `makeCampRaider` は削除せず登録したまま保持。野営地では新しい `campGuard` を使う。
- 戦闘ステータスは旧 `raider` 設定を共有する。敵数、敵IDの範囲、野営地の位置、宝箱条件、追跡・攻撃AI、ダメージ通信は変更しない。
- v42 hotfix に含まれていた `Shared.springTerrainOffset()` の修正も維持し、`shared.js` の読み込みキャッシュキーを v43 に更新。
- `world.json` は含めていない。

## テスト
- `test/camp-guard-model.js`: 比率、モデル登録、旧モデル保持、敵ID維持、バージョン表示を検証。
- 既存テストはWebSocket smokeテストを除く22本が合格。インラインJavaScript、`shared.js`、`server.js` の構文チェックも通過。
