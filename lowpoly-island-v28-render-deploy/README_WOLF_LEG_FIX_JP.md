# v37 オオカミの脚の配置修正

v35で四足動物のモーション用リグを追加した際、旧・新オオカミ共通の脚の回転中心のX座標に、左右の符号（±1）をそのまま使ってしまっていました。結果として脚が胴体から大きく離れて配置されていました。

- 修正前: `pivot.position.set(sx, 0.35, sz)` 相当（左右 ±1）
- 修正後: `pivot.position.set(sx * 0.16, 0.35, sz)`（左右 ±0.16）
- 歩行モーションの交互動作に使う `side` は ±1 のまま維持しています。
- オオカミの新旧モデル両方に適用されます。イノシシ、AI、攻撃判定、背中パーツ、柵建築などは変更していません。

## 原因
はい。動物モーション追加時の座標指定ミスです。アニメーションそのものではなく、関節の配置座標の誤りで、モーションを追加した v35 から入った問題です。
