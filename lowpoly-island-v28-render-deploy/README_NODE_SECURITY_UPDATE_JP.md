# Node.js セキュリティ更新（2026-10-21）

この更新は、ゲームコードや通信仕様を変えず、Render 上の Node.js 実行バージョンを固定するものです。

- 2026年10月21日公開の Node.js 24.22.1（LTS）を指定しています。
- `.node-version` をリポジトリのルートにも置いています。Render のバージョン指定では、環境変数 `NODE_VERSION` がファイルより優先されるため、設定済みなら `24.22.1` に合わせてください。
- `package.json`、`package-lock.json`、ゲームのソースコード、ワールド保存形式は変更していません。

再デプロイ前に現在のワールドを必ずエクスポート／バックアップしてください。Render の永続ディスクを使っていない場合、再デプロイ後に `world.json` が残る保証はありません。デプロイ後は Deploy Logs で Node.js の稼働バージョンを確認してください。
