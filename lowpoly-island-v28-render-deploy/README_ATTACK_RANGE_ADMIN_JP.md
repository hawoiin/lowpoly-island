# v42 — 敵の攻撃予告範囲表示を管理者が切り替え

- タイトル画面のバージョン表示を `v42` に更新。
- 設定 → ワールド管理（管理者専用）に「敵の攻撃範囲表示を有効にする」を追加。
- 初期状態はOFF。管理者がONにすると、敵およびボスが攻撃準備中に地面へ表示する赤い範囲が全参加者に表示される。
- この設定は見た目だけに作用し、攻撃のタイミング・命中範囲・ダメージ計算は変更しない。
- サーバー側で管理者認証を必須にし、新規接続者にも現在の設定を送る。
- 設定はサーバー起動中だけ有効。再起動後は安全側のOFFへ戻る。
- 野営地の人型番人や、既存のゲーム動作は変更していない。
