# v60.3 ローグライク遺跡の敵向き・帰還後戦闘修正

## 修正内容
- ダンジョン敵・守護者の顔がローカル -Z を向くモデル構造に合わせ、追跡時にプレイヤーへ正面を向く回転式へ修正。攻撃距離内でも向きを更新。
- ローグライク遺跡では、通常出口・深層の生還門・死亡後の帰還のいずれからも、所定の島側出口への遷移をサーバーが受け付けるよう修正。死亡・出口・生還門以外からの不正な退室ワープは引き続き拒否。通常洞窟の出口検証は維持。
- 遺跡から帰還した瞬間に insideCave 状態も解除し、1フレームのシーン状態不一致を防止。
- 帰還後はサーバー上の cave 状態が -1 に戻るため、フィールド敵の追跡・攻撃と、プレイヤーからの通常攻撃が再開される。

## 確認
`node test/rogue-dungeon-transition-combat.js` と `node test/validation.js` を実行。ほかの依存不要テストも個別実行する。
