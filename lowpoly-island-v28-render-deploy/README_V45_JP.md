# v45 更新内容（柵・野営地・地上洞窟）

## 柵の囲いを閉じやすく
- 柵を連続して配置していなくても、既存の柵の開いた端どうしが1本で届く範囲にあり、カーソルが隙間の近くにある場合は自動接続候補を表示します。
- 最後の柵の長さと向きを自動計算します。
- 1本で届かない隙間や、カーソルから離れた柵は自動では閉じません。

## 野営地を3か所に
- 既存の野営地の場所は維持し、追加2か所をseedから再現可能な形で生成します。
- 各野営地に人型の番人を4体配置します。
- 最初の野営地の宝箱index 5と海底洞窟の宝箱index 6は維持し、追加の野営地の宝箱は後ろに追加します。
- 保存データに既に記録された開封状態は維持されます。

## 地上洞窟を遺跡風ダンジョンに
- 現在の画面切り替え方式はそのまま維持し、洞窟内部に中央祭壇、柱、ルーン壁面、石畳の導線を追加しました。
- 装飾中心の追加で、移動・衝突判定・アイテム・敵AIは変更していません。

## 注意
- タイトル画面のバージョン表記は v45 です。
- 既存の `world.json` は配布ZIPに含めていません。更新時に既存のワールド保存ファイルを削除・上書きしないでください。
- 自動テストはコード上の回帰を確認するもので、Render上でのブラウザ目視確認の代わりではありません。
