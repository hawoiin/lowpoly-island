# v55 — 野営地番人の棍棒を自然に構える

## 変更内容
- 野営地番人の棍棒は、手のローカル座標で柄・先端が手より下側へ伸びる既存モデルを維持。
- 待機・歩行時の右肩と肘を曲げた基準姿勢に変更し、階層回転を合成した結果、棍棒の太い先端が握り位置より上かつ前方に来るように調整。
- 予備動作・振り下ろし・回復の各フェーズを新しい待機姿勢に対する相対角度へ調整。フェーズ境界で肩・肘・手首が連続するようにした。
- 攻撃のサーバータイミング、ダメージ、敵AI、当たり判定、ワールド保存形式は変更なし。
- タイトルのバージョン表示と `shared.js` のキャッシュキーを v55 に更新。

## 確認
- 棍棒の先端位置を、Three.js の関節階層に沿った回転計算で検証するテストを更新。
- 実際のブラウザ画面・Render上の見た目はこの環境では確認していない。デプロイ後に野営地の番人の待機姿勢、歩行、振りかぶり、振り下ろし、復帰を目視確認する必要がある。
