# v58 — ローグライト・ダンジョン追加

## 追加内容
- 島に古代門を新設。近づいて E（スマートフォンは GET）で拠点を開き、挑戦開始または恒久強化を選択。
- 専用インスタンスの円形ダンジョン。部屋ごとに石材・結晶の配置と色調を変え、敵編成は階層に応じて増加。
- 敵を全滅させると3択報酬が出現。攻撃強化、吸血、軽減、速度、回復、一度だけの復活などから選ぶ。
- 5層ごとに守護者が出現。クリアした階層の深淵の欠片はブラウザ内に保存され、死亡しても失わない。
- 欠片で刃・防御・速度の恒久強化を購入。通常ワールドの所持品・建築物・宝箱・セーブデータは使わず、変更もしない。
- ダンジョン内の敵と進行は各プレイヤーの個別ランとして扱う。島のマルチプレイ、既存洞窟、サーバー敵AIとは分離。
- 既存の v57 番人の棍棒保持姿勢はそのまま維持。

## 操作
- 島の古代門に近づいて E（スマートフォンは GET）で拠点を開く。
- 「ダンジョンに挑む」で開始。戦闘は通常のクリック／攻撃ボタン、移動は既存操作。
- 敵を全滅させたら報酬を1つ選び、部屋中央の発光門に近づいて E で次の層へ。
- 入り口側の門に戻って E を押すと撤退。死亡時はリスポーンを押し、入口まで戻って門から帰還。
- 恒久強化は古代門の拠点画面で購入可能。

## データと注意
- 恒久強化通貨は `localStorage` の `lowpoly-island-rogue-meta-v1` に保存。通常ワールドのセーブ形式は変更しない。
- 今回はプレイヤーごとの個別ダンジョンです。協力プレイで同じ敵・報酬状態を共有する設計ではありません。
- 自動テストはコード上の構造と回帰の一部を確認します。ブラウザでの目視操作確認、特に敵AI・門の距離・スマートフォンUIは実機確認が必要です。
