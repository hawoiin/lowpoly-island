# v35 動物モーション更新

v34を基準に、狼・猪の動作を追加した更新です。既存の敵AI、攻撃のダメージ、攻撃範囲、移動速度、再出現時間、マルチプレイの状態同期は変更していません。

## 追加した動作

- 通常版と旧デザイン版の狼・猪（計4種類）を関節付きのモデル構造に変更
- 待機中の呼吸、頭・尾の小さな動き
- 歩行・走行時の脚の交互運動（対角の脚を組にした歩行）と胴体の上下動
- 攻撃前に身構える動き、突進時の姿勢、攻撃後の回復姿勢
- 被弾時の短い反応
- 倒されたときの短い横倒れモーション

動作は各クライアントで補間・再生し、サーバー側の敵AIやダメージ計算は変えていません。倒された狼・猪は見た目の倒れモーション後に画面から消えますが、サーバー上では倒された時点で既に死亡扱いです。

## 反映方法

Renderの既存設定を変える必要はありません。現在のGitHubリポジトリの `lowpoly-island-v28-render-deploy` 内で、同じパスのファイルを更新してください。

- `public/index.html`
- `package.json`
- `test/animal-animations.js`（追加）

既存の `world.json` は、この更新ZIPには含めていません。ワールドの保存データを誤って初期状態に戻さないためです。既存ファイルを保持したまま上記ファイルだけを更新してください。

## 検証

`node test/animal-animations.js`、既存の非通信系テスト、JavaScriptの構文チェックを実行しました。`npm test` のうちWebSocket起動を必要とする `test/smoke.js` は、この作業環境に `ws` パッケージが存在しないため完了できていません。Renderのデプロイ後にブラウザ上で動作を確認してください。
