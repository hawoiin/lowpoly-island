# 柵の囲いを閉じる補助（v34）

## 追加内容
- 柵を続けて設置すると、最初の柵の空いている端点を建築中の始点として記憶します。
- 2枚目以降を接続していくと、現在の開いた端点を追跡します。
- 最後の隙間が1枚の柵で届く範囲（0.65〜2.6m）で、通常の連続設置位置にプレビューを近づけると、始点と終点を結ぶ緑色の柵プレビューに自動切り替えします。
- 緑色の球が閉じ先を示します。クリックまたはEnterで設置すると、最後の柵の角度と長さが自動調整され、囲いが閉じます。
- 最後の柵の長さはオンライン参加者に同期され、ワールドの保存・復元・バックアップにも保持されます。
- 隙間が2.6mより広い場合は、途中にもう1枚以上の柵を置いてください。0.65m未満や、接続先の高さ差が大きい場合は自動閉鎖しません。

## Render反映方法
1. ZIPを展開します。
2. `lowpoly-island-v28-render-deploy` フォルダ内のファイルを、GitHubの同名フォルダに同じ階層で反映します。
3. 新しい `test/fence-closure.js` も追加し、`main` ブランチにコミットします。
4. Renderの再デプロイ完了後、公開サイトで確認します。

RenderのRoot Directory（`lowpoly-island-v28-render-deploy`）は変更不要です。
