# v60 — StarBreak風・深層ダンジョン再構築

## 目的
小さな闘技場で敵の群れを倒し続ける方式ではなく、3Dの地形を探索し、分岐・段差・橋・宝箱・敵を自分の操作で攻略していくアクションローグライクに再設計。StarBreakの挑戦と戦利品の流れ、Deep Rock Galacticの自然洞窟のシルエット、Remnant IIの遺跡区画の見せ方を要素別に参考にする方針です。

## ダンジョン
- 通常洞窟を置き換えず、第3の入口から専用の大規模な深層遺跡へ入る。
- 複数の広間と長い回廊、左右の枝道をつなぎ、低地の地下水、高台、深層へ下る斜路を配置。
- 中央広間は床メッシュに穴を作った大亀裂にし、中央の石橋と東側の細い橋以外では横断できないよう歩行判定を設定。東側の橋はその先で水晶の低地へ下る斜路につながります。
- ひび割れた不規則な床輪郭、崩落した石縁、橋の欠けた欄干、亀裂の底の結晶、階層ごとの柱・岩縁で空間の読みやすさを補う。
- 形状・床高・封印門・歩行可能領域は同じ座標定義を使用。高台と斜路にプレイヤー・敵・宝箱が追従する。

## 遊びの流れ
- 主進路の敵を倒して封印門を開く。枝道の敵は任意討伐で、倒すと欠片を得られ、宝箱から装備も狙える。
- 武器・防具の強さは一回の冒険中に入手した装備で変わり、生還時に欠片を持ち帰って恒久強化する。
- 挑戦ごとに敵位置と宝箱位置を少し変え、固定マップでも毎回同じ戦闘配置にならないようにする。
- 通常の島、通常洞窟、建築、野営地番人の棍棒保持は維持する方針。

## 検証上の注意
静的JavaScript構文検査と回帰テストを実行します。ブラウザ内での全ルート踏破、実機上の描画、マルチプレイで敵・宝箱を共有する統合試験は別途確認が必要です。
