# v39 泉の配置地点を平坦な地形に限定する修正

## 変更内容
- 泉は水面・池底を水平のまま維持するため、見た目を地形に無理やり合わせるのではなく、配置候補の選び方を変更。
- 泉の中心、中間リング、外周を合計25点で調べ、範囲内の地形高低差が38cmを超える場所は候補から除外。
- 平坦な場所を探せるよう、候補探索の上限を400回から3000回に拡大。
- 泉の回復範囲・回復量、水面・池底の描画、地形生成、衝突判定、セーブ形式は変更しない。
- 配置地点がseedから決まる仕組みは維持し、同じseedでは常に同じ位置になる。

## バグ回避上の注意
- 野営地は旧泉位置を使って座標を計算するため、泉の再配置だけでは既存の野営地位置が変わらない。新しい泉側が野営地から30m以上離れる。
- 旧いセーブ形式自体は変更していない。バックアップから復元する場合は、現在のコードのレイアウト版と一致することを確認する。
