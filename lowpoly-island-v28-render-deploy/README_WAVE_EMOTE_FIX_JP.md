# v32 — 手を振るモーションの腕の向きを修正

## 変更内容
- v30を基準にしています。v31の肩位置変更は含めていません。
- 「手を振る」エモートの上腕のX回転に入っていた約-0.75ラジアンの後方への傾きを外しました。
- 腕を上げる角度のアニメーション、テンポ、胴体の揺れ、他のエモートは変更していません。
- 自分のキャラクターと他プレイヤーの表示は共通の `getEmotePose` を使うため、同じ修正が適用されます。

## 反映
GitHubのRoot Directory内で、ZIPの同じパスにあるファイルを上書きしてください。主な変更は `public/index.html` です。テスト用に `test/name-emote.js` も含まれます。

## 確認
`npm test` に含まれる既存テストと、追加した「上腕が後方へ大きく倒れない」回帰テストを実行します。実画面での目視確認は、Renderへの反映後に行ってください。
