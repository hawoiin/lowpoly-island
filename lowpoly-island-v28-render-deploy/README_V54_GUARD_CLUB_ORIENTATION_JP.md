# v54 — 野営地番人の棍棒の保持角を修正

## 変更点
- 棍棒の柄・太い先端を専用の親グループにまとめ、武器自体を約26度前方へ傾けて保持するように変更。手の位置や腕の長さ、武器の部品サイズは変更していません。
- 攻撃中は手首の回転で保持角を補正し、v52の頭上への振りかぶり・前下方への振り下ろし軌道をできるだけ維持。補正は予備動作で滑らかに入り、回復中に待機角へ戻ります。
- 敵AI、攻撃時間、ダメージ、当たり判定、武器の衝突判定、ワールド生成、セーブ形式は変更していません。
- Node.js 24.22.1 の指定と既存の `ws` ロック版 8.22.0 は維持しています。
- タイトル画面のバージョン表示を v54 に更新。

## 確認
`node test/camp-guard-attack-animation.js` と `node test/camp-guard-model.js`、`node test/version-label.js` で、待機時の棍棒先端が手より低く、前方へ傾き、地面から離れていること、攻撃前後の手首補正が連続していることを確認します。実際のブラウザ画面とRender上の見た目は、デプロイ後に別途確認が必要です。

## 適用前の注意
Renderへ反映する前に、共有ワールドのバックアップを別の場所に保管してください。変更は `lowpoly-island-v28-render-deploy/public/index.html` とテスト・説明・バージョン情報に限定しています。
