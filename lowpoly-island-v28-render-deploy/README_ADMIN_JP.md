# 管理機能（v33）

## Render設定
- RenderのWeb Service `lowpoly-island-multiplayer` → Environment に `SAVE_ADMIN_TOKEN` を設定。長くランダムな値を使い、GitHubには書かない。
- 値を変更した場合は再デプロイする。認証は現在のWebSocket接続単位で、再接続時には再認証が必要（ページ上の入力欄にキーが残っている間は自動で再認証を試す）。

## ゲーム内
- 設定 → ワールド管理 → 管理者キーを入力 →「管理者として認証」。
- オンラインプレイヤー一覧を手動更新でき、接続中の参加者と接続時間を確認できる。自分自身はキックできない。キックされた参加者は自動再接続せず、ページを再読み込みすると再参加できる。現在の実装はキックのみで、再入室禁止（BAN）は行わない。
- 「今すぐバックアップ」は共有ワールド（地形シード、建築物、宝箱状態）だけをJSONでダウンロードする。Renderのローカルファイルに長期保管する仕組みではないため、ファイルは手元など別の場所に保管する。
- 「バックアップから復元」は本ゲームが出力した `lowpoly-island-world-backup` JSONを読み込む。復元前の現在のワールドも自動でJSONダウンロードする。復元は全参加者に影響するため、操作前に確認が表示される。

## セキュリティ
- 管理操作はサーバーで認証を確認する。ブラウザのボタンを隠すだけの実装ではない。認証失敗は接続単位で試行回数を制限する。
- 管理者キーはブラウザのlocalStorageには保存しない。入力欄はそのページを閉じるまで残る場合がある。共有PCではログアウトしてページを閉じる。
- Renderの無料インスタンスのローカルファイルは永続バックアップ先として扱わず、ダウンロードしたバックアップを別に保管する。
