# 野営地の人型番人（v40〜v43）

- v40で野営地の敵4体を野生生物から人型へ変更。敵ID範囲、野営地位置、宝箱条件は維持。
- v43では野営地の表示モデルを `campGuard` に変更。プレイヤーに近いデフォルメ比率（大きめの箱型頭、幅広い胴体、短く太い四肢）で組み直し、棍棒の攻撃と既存の近接AIを再利用。
- v40の細身で装備の多い `raider` / `makeCampRaider` モデルは削除せず、別の敵に転用できるよう登録したまま保持。
- 旧・新モデルは別のモデル生成関数とkindで管理。野営地の敵数、ID範囲、HP、攻撃力、攻撃距離、再出現、宝箱ロックは変えない。
