# v52 — 野営地番人の攻撃モーション再調整

この版は v51 を基準に、野営地の番人が棍棒を振り下ろす動きを調整した更新です。

- 構えでは棍棒を頭上かつ少し前へ持ち上げる。
- 肩の前後回転を主軸にして、腕と棍棒が攻撃中に真横へ大きく振り出されないようにする。
- 胴体の前傾、肘、手首を連動させ、棍棒を前下方へ振り切る。
- 回復動作は攻撃終端から自然に通常姿勢へ戻す。
- 攻撃AI、攻撃予告時間、ダメージ、攻撃判定、敵ID、建築物・ワールド保存形式は変更しない。

## テスト
`node test/camp-guard-attack-animation.js` で関節階層から計算した棍棒先端の高さ・前後方向・左右方向を検証する。

配布物には `world.json` を含めていません。ブラウザ・Render実環境での見た目の最終確認は、更新後に野営地で行ってください。
