# v44 — 野営地番人専用の棍棒攻撃モーションを追加

- タイトル画面右下のバージョン表示を `v43` に更新。
- 野営地に、プレイヤーと近い比率（大きめの箱型頭・幅広い胴体・短く太い手足）の新しい番人 `campGuard` を配置。
- 以前の細身で装備の多い人型モデル `raider` / `makeCampRaider` は削除せず、別の敵に使えるよう保持。
- 野営地の敵数、敵ID範囲、戦闘ステータス、攻撃AI、宝箱条件は維持。新しいモデルは同じ既存の番人用戦闘設定を使う。
- `world.json` は配布物に含めていない。既存のワールド保存データを維持する。

- 攻撃前に棍棒を頭上へ振りかぶり、胴体をひねって前方へ振り下ろし、振り切った後に戻る専用アニメーションを追加。
- サーバーの攻撃予告時間・攻撃判定・ダメージは変更していない。
