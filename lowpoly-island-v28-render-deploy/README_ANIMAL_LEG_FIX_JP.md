# v37 オオカミの脚パーツ配置修正

## 原因
v35で歩行・走行などの関節モーションを追加した際、旧・新オオカミで脚の関節グループの横位置に、左右を示す `-1 / 1` をそのまま使うミスが入りました。旧モデルの元の位置は左右 `-0.16 / 0.16` だったため、モーション追加時から脚が胴体の外側へ大きく離れていました。

## 修正
- 脚の回転中心を `sx * 0.16` に修正。
- 歩行サイクルに用いる左右符号（`side` が -1 / 1）と、実際のモデル座標を分離。
- 旧・新オオカミの両方に適用。
- イノシシ、動物AI、攻撃や当たり判定、背中パーツなど他の仕様は変更なし。

## テスト
`node test/animal-animations.js` を含む、サーバー通信を必要としない既存テストを実行。新しい脚の横位置回帰テストも追加。
